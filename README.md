# SGA — Current English Edition

This is the independently discoverable English-language publication surface
for SGA 1 through SGA 7 II. Start with `00_SGA_EN_CUMULATIVE_LINKED_READER.pdf`.
Nine component readers remain directly downloadable. Exact scope and omissions
are stated in `COMPONENT_COVERAGE.tsv`. Editable source and exhaustive
production/provenance evidence are bundled separately.

This record is one evolving whole-SGA English DOI lineage. It does not mint
separate DOIs for volumes, exposés, or component readers. It is a language
component of the stable global SGA hub DOI 10.5281/zenodo.20410947.
