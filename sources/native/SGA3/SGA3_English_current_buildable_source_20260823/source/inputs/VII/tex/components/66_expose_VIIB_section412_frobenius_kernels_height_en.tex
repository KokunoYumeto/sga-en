
\subsubsection*{4.1.2}
\phantomsection
\label{sga3:VIIB:4.1.2}

Let \(G\) be a formal group over \(k\) with affine algebra \(A\). Since
the functor
\[
  X\longmapsto
  X\widehat\otimes_\pi k
\]
commutes with finite products, it carries formal \(k\)-groups to
formal \(k\)-groups. Moreover, since \(\operatorname{Fr}(X/k)\) is
functorial in \(X\), the morphism
\[
  \operatorname{Fr}:G\longrightarrow G^{(p)}
\]
is a homomorphism of formal \(k\)-groups. If one puts
\[
  G^{(p^{\,n+1})}
  =
  \bigl(G^{(p^n)}\bigr)^{(p)},
\]
the same is true of the composite morphism
\[
\begin{aligned}
  \operatorname{Fr}^{n}
  =
  \operatorname{Fr}^{n}(G/k):
  G
  &\xrightarrow{\ \operatorname{Fr}\ }
  G^{(p)}
  \xrightarrow{\ \operatorname{Fr}\ }
  G^{(p^2)}
  \xrightarrow{\ \operatorname{Fr}\ }
  \cdots
  \xrightarrow{\ \operatorname{Fr}\ }
  G^{(p^n)}.
\end{aligned}
\]
The kernel of this homomorphism \(\operatorname{Fr}^{n}\) will be
denoted \(\operatorname{Fr}_nG\). It follows directly from the
definitions that \(\operatorname{Fr}_nG\) is radicial and has as
affine algebra the quotient
\[
  A/I_A^{\{p^n\}},
\]
where \(I_A^{\{p^n\}}\) denotes the closed ideal of \(A\) generated
by the \(p^n\)-th powers of the elements of \(I_A\). When
\(I_A^{\{p^n\}}\) is zero, that is, when
\(\operatorname{Fr}_nG=G\), one says that \(G\) is \emph{of height
at most \(n\)}.
