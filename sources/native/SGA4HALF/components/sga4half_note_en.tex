
\section*{Typesetter's Note}

This is a \LaTeX{} rendition of Deligne's \emph{Cohomologie \'Etale},
Lecture Notes in Mathematics 569, Springer-Verlag. The typesetting was done by
Daniel Miller. The source code may be found on GitHub
(\url{https://www.github.com/dkmiller/sga4.5}). It is an essentially
unmodified version of the original. Most changes are slight, for example the
use of script rather than roman letters for sheaves. The most substantial
change is that $\Hom$ denotes ``sheaf Hom'' and $\rHom$ its derived functor,
whereas $\rhom$ denotes the derived functor of the ordinary Hom functor.
Comments or corrections concerning that typesetting may be sent to
\url{dkmiller@math.cornell.edu}.
