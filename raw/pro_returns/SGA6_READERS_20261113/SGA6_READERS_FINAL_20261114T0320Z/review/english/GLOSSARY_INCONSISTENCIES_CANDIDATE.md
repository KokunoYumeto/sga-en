# Candidate English terminology variations
## Scope and status
This is an unfinished terminology audit of the supplied native English corpus. It lists candidate variations requiring paired French–English context review. It does not establish that two English expressions translate the same French occurrence, and it does not authorize a bulk replacement.
The reference glossaries yielded 1116 French/English candidate pairs whose French expression occurs literally in the supplied corrected French. Of these, 128 French expressions have two or more reference renderings that also occur somewhere in the supplied English.
Counts are exact case-sensitive literal matches in the TeX document body, with alphabetic boundary guards. They include headings, comments and mathematical operands; they exclude the preamble. They are surface-form counts rather than semantic term-frequency counts. Inflections, capitalization, accents and mathematical command spellings have not been merged. Counts refer to the supplied native corpus before the new page-by-page English replacements.
All choices below remain open until the French and English occurrences are paired. Several reference glossaries themselves preserve both spellings, for example fiber/fibre. Those rows therefore require an edition decision grounded in the source contexts; literal frequency does not decide the rendering.
